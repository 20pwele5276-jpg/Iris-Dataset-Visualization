# Iris Dataset Visualization (Task 1)

## What this task is about
In this task, I worked with the Iris dataset to understand how data looks and how different features are related to each other.

The goal was to explore the dataset, summarize it, and create simple visualizations to see patterns.

## What I did
- Loaded the Iris dataset using Python
- Checked basic information like shape, columns, and data types
- Used summary statistics to understand the data better
- Created visualizations:
  * Scatter plot to see relationships between features
  * Histogram to understand data distribution
  * Box plot to detect outliers

## Tools I used
- Python
- Pandas
- Matplotlib
- Seaborn

## What I learned
I learned how to explore a dataset step by step and how visualizations can help in understanding patterns in data.

## Result
The dataset was successfully analyzed and visualized, and clear patterns between different Iris species were observed.
